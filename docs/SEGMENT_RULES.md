# 切段規則（Phase 3，依真實資料驗證後修訂）

實作：`src/citecheck/segment.py`，純規則、無 LLM。

## 1. 版面切分
`JFULL` 依單獨成行的標題切成四部分：
- **header**：「主文」之前（法院、案號、當事人、案由）→ 合為 1 段，角色 UNKNOWN。
- **main**：「主文」到「理由」（或「事實及理由」「事實」）之間 → 每段 `MAIN_TEXT`。
- **reason**：理由本文 → 逐段判角色（見 §3）。
- **footer**：第一行形如「中華民國 N 年 N 月 N 日」起至結尾（法官、書記官）→ 合為 1 段，UNKNOWN。
- 沒有「理由」標題者（如核定律師酬金裁定），主文之後到日期行皆視為 main。
- header / footer 的 UNKNOWN 不算入「UNKNOWN 比例」（下稱「理由段 UNKNOWN」）；Phase 4 檢索時我預設略過 header、footer（規格說 UNKNOWN 也納入，待確認）。

## 2. 斷行重組（原文為固定寬度硬換行）
實際資料有兩種版面：(a) 續行縮排 4 格；(b) 全部靠左、無縮排。
- 新段落起點：以編號開頭（`一、` `㈠` `⒈` `（一）` `1、` `1.`），**且前一行以 `。；：`（可帶括號／引號）結尾**；數字編號後不可緊接數字（避免把換行後的「0、000」當編號）。
- 無編號的新段落：前一行以 `。；：` 結尾，且 (a) 本行縮排 < 4，或 (b) 前一行長度 < 該文件第 90 百分位行長的 80%，或本行以「據上論結／惟按／惟查／本院／經核」開頭。

## 3. 角色判定與狀態延續
段落（去掉開頭編號後）依序比對，**先中先贏**：
1. PARTY_CLAIM：上訴人主張、被上訴人主張、本件上訴人主張、被上訴人則以、上訴人則以、原告主張、被告則以、再抗告人主張、抗告意旨、上訴意旨、上訴論旨（規格起始清單）。
2. LOWER_COURT：原審、原法院、原判決、第一審。
3. SUPREME_COURT：本院、按、惟按、惟查、查、經核、據上論結。
4. **（新增）當事人陳述句**：段首 40 字內、第一個 `，。：；` 之前出現 `主張／則以／辯稱／抗辯／陳稱／略以` → PARTY_CLAIM。理由：真實判決多寫「本件被上訴人主張：」「上訴人○○則以：」「廖冠豪2人辯稱：」，規格清單不含這些寫法。
5. 都不符 → 沿用前一段角色（理由段起始為 UNKNOWN）。

規格特別規則 4：標記詞只看**段落開頭**，句中的「上訴意旨／上訴論旨」不切換角色（有單元測試）。

## 4. 驗證結果（全部 336 份最高法院民事判決）
| 版本 | 理由段 UNKNOWN | UNKNOWN 超過三成的判決 |
|---|---|---|
| 規格起始清單 | 10.4% | 30 / 336 |
| 加入「當事人陳述句」與斷行修正後 | 1.4%（47 / 3,271 段） | 1 / 336 |

未超過規格 §11 的三成門檻。

## 5. 已知限制（請人工檢查時特別留意）
- 角色以**段落**為單位。若最高法院在同一段內先複述上訴意旨再駁斥（「上訴人主張…，惟…」），整段會被標為 PARTY_CLAIM。
- 「從而」「綜上」「經查：」等不列為標記詞，沿用前一段角色；在原審理由內是對的，但在本院段內若緊接當事人段落則可能標錯。
- 「按」「查」是單字標記，理論上可能誤中以這些字起頭的其他詞。
- 同一版面中，無縮排版面的新段落判斷依賴行長啟發式，偶爾會把兩段合併。
- 僅用 336 份判決（2026/02–08）驗證，裁定未納入統計。

## 6. 裁定補充（Phase 4 之後）
- 問題：以判決驗證的規則用在裁定時，理由段 UNKNOWN 22.6%（5617 段中 1268 段；2185 份裁定中 486 份過半為 UNKNOWN）。
- 原因一：資料中部分編號用私人使用區字元（如 U+F6AE）而非「三、」，導致「據上論結」等標記詞被前綴蓋住（約 100 段）。現已將 U+E000–U+F8FF 視為編號。
- 原因二：裁定常直接說理（「上訴第三審法院，非以…」「上訴人對於原判決提起上訴，雖以…」「本件再抗告人…」），無標記詞。現規則：**文書首行含「裁定」者，理由段起始角色為 SUPREME_COURT**（判決仍為 UNKNOWN）。
- 結果：裁定理由段 UNKNOWN 0.0%（SUPREME 5432、PARTY 156、LOWER 47）；判決不變（1.4%）。
- 風險：裁定中「聲請人…以伊生活困難…為由聲請」這類不含「主張／則以／辯稱／抗辯／陳稱／略以」的當事人陳述，會被視為最高法院段落，可能把當事人說法誤判成 COURT_HOLDING。尚未人工抽檢裁定樣本；Phase 5 評測時請留意。
