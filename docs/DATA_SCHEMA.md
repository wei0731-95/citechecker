# DATA_SCHEMA（Phase 0，依實際檔案）

## A. 法規：`data/raw/laws/FalV/FalV.xml`（**XML，非 JSON**）
- 同目錄有 `manifest.csv`、`schema.csv`（欄位標題表）、`FalV.zip`（原壓縮檔）。
- 根節點 `<LAWS UpdateDate="2026/11/6 上午 12:00:00">`；共 **1351** 個 `<法規>`（法律 1342、憲法 9）。法規名稱無重複。
- `<法規>` 子節點：法規性質、法規名稱、法規網址、法規類別、最新異動日期(YYYYMMDD)、生效日期、生效內容、廢止註記、是否英譯註記、英文法規名稱、附件、沿革內容、前言、`<法規內容>`。
- `<法規內容>` 內含交錯的 `<編章節>` 與 `<條文>`；`<條文>` 只有 `<條號>`、`<條文內容>`(CDATA)。
- 條號寫法：`第 184 條`、`第 15-1 條`（「之一」為連字號；數字前後有空白）。例外：憲法增修條文等 28 筆條號為純數字（如 `1`、`2`、`11`）。
- 刪除條文：內容恰為 `（刪除）`（全形括號），共 1021 條；未見半形 `(刪除)`。
- 廢止：`<廢止註記>` 為 `廢` 者 **322** 部（如動員戡亂時期臨時條款）；其餘為空白（1029 部）。
- 例：民法 1439 條（修正 20260817）、民事訴訟法 800 條、公寓大廈管理條例 66 條。

## B. 判決：`data/raw/judgments/<YYYYMM>--(20261016Update)/<YYYYMM>/<法院+案類>/*.json`
- 現有 **202602–202608 共 7 個月**（已解壓，另有 .rar）。每筆一個 JSON，檔名即 JID。欄位（皆為字串）：`JID, JYEAR, JCASE, JNO, JDATE, JTITLE, JFULL, JPDF`。
- JID：`TPSV,115,台上,321,20260819,1` = 法院代碼,案號年度,字別,號數,裁判日期,版本序號。
- 最高法院民事 = 目錄 `最高法院民事`，JID 前綴一律 `TPSV`（刑事 `TPSM`，行政 `TPAA`）。**法院代碼可可靠區分民刑事。**
- 最高法院民事共 **2521** 筆；裁判日期 20260203–20260827；各月：02:246 03:373 04:378 05:365 06:376 07:370 08:413。
- 文書種類取自 `JFULL` 第一個詞：民事裁定 2182、民事判決 336、民事提案裁定 2、民事大法庭裁定 1。
- 字別：台上1167、台聲583、台抗493、台簡抗214、台簡聲27、台簡上24、台再12、**台上大1**（`TPSV,111,台上大,932,20260612,1`，大法庭裁定，J10 有真實例）。
- 案號年度 JYEAR：110:2、111:2、112:2、113:16、114:218、115:2281。**多數為 114–115 年度；109 年以前案號完全沒有。**
- (JYEAR,JCASE,JNO) 重複 39 組；其中 19 組無法以判決／裁定區分（同為裁定，如 115 台聲 138），查詢會是 AMBIGUOUS。

## D. 待確認問題
1. **涵蓋仍偏窄**：案號年度幾乎只有 114–115，書狀常引用的 109 年以前判決都會是 DATA_NOT_COVERED。裁判日期僅 2026/02–08。是否可接受？測試集 A–E 類須取自這 2521 筆。
2. **涵蓋判斷基準**：§6.5 寫「裁判年月」，但書狀引的是案號年度。建議：以匯入資料的「案號年度」最小～最大（110–115）判斷，且 110–113 年度因資料極少，也可能誤報 NOT_FOUND_IN_SCOPE。請決定用案號年度、裁判年月，或改成以「裁判日期涵蓋 2026/02–08，且案號年度 ≥ 某值」判斷。
3. **doc_kind**：「提案裁定」「大法庭裁定」擬歸為 doc_kind=裁定，其中大法庭（字別含「大」）一律 OUT_OF_SCOPE。
4. 字別清單 8 種來自此 7 個月，仍可能漏（如台簡再）。接受？
5. 法規 XML 含已廢止 322 部：擬匯入時排除。憲法增修條文 28 筆純數字條號：擬保留原樣。
6. Python 3.11 以 Docker（python:3.11-slim）處理。
